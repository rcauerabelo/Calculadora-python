# Calculadora-python
Calculadora em Python que reúne operações básicas, funções científicas (potenciação, raízes, trigonometria) e conversão de unidades. Conta com integração a uma API de câmbio para consultar taxas e realizar conversões de moedas em tempo real no terminal. Projeto prático e funcional, ideal para estudos e automação de cálculos do dia a dia.
